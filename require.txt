3. Mô tả bài tập: Building Back-End with Golang
Bạn sẽ xây dựng một REST API hoàn chỉnh bằng Golang, kết nối database, có authentication, middleware, và deploy được. Bài tập gồm 3 phần: xây dựng API, authentication & middleware, và tối ưu & deploy.
Chọn một trong các đề tài sau:Hệ thống quản lý công việc (Task Management): User, Project, Task, Comment.Hệ thống blog (Blog API): User, Post, Category, Comment, Like.Hệ thống thương mại điện tử mini (E-commerce API): User, Product, Category, Cart, Order.Hệ thống quản lý thư viện (Library API): User, Book, Author, Borrow, Return.Hệ thống đặt vé xem phim (Movie Ticket API): User, Movie, Cinema, Showtime, Ticket.Phần 1: Xây dựng REST API (bắt buộc)
Sử dụng Gin, Echo, hoặc Fiber làm web framework.
Xây dựng ít nhất 5 endpoint CRUD cho mỗi resource chính (GET, POST, PUT, DELETE).
Kết nối database (PostgreSQL hoặc MySQL) bằng GORM hoặc sqlx.
Cấu trúc project rõ ràng: handlers/, services/, repositories/, models/, middlewares/, configs/.
Xử lý lỗi tập trung (centralized error handling), trả về JSON response chuẩn.
Validation input bằng thư viện validator.
Viết unit test cho ít nhất 3 handler hoặc service bằng testing package và testify.
Phần 2: Authentication & Middleware (bắt buộc)
Xây dựng chức năng đăng ký (register) và đăng nhập (login).
Sử dụng JWT (JSON Web Token) để xác thực.
Mã hóa mật khẩu bằng bcrypt.
Viết middleware xác thực JWT, bảo vệ các route private.
Viết middleware logging (ghi log request/response).
Viết middleware CORS.
Phân quyền user (admin, user) nếu có thể.
Phần 3: Tối ưu & Deploy (bắt buộc)
Viết Dockerfile multi-stage build cho ứng dụng Go.
Viết docker-compose.yml để chạy app cùng database.
Thêm caching với Redis cho các endpoint thường truy vấn.
Thêm rate limiting middleware.
Viết API documentation bằng Swagger (swaggo) hoặc Postman collection.
Deploy lên VPS, Render, Railway, hoặc Fly.io.
Viết CI pipeline với GitHub Actions (lint, test, build).
Bonus (thêm điểm sáng tạo):
Thêm pagination, filtering, sorting cho các endpoint GET.
Thêm soft delete cho các resource.
Thêm background job (ví dụ: gửi email) bằng goroutine hoặc worker pool.
Thêm WebSocket cho real-time notification.
Thêm graceful shutdown cho server.
Thêm Prometheus metrics và health check endpoint.
Viết integration test với testcontainers.

5. Hướng dẫn thực hiệnSetup project: Dùng go mod init để khởi tạo module. Chọn Gin nếu mới bắt đầu vì cộng đồng lớn, tài liệu nhiều.Cấu trúc thư mục: Chia rõ ràng: cmd/ (main), internal/ (handlers, services, repositories, models), pkg/ (utils), configs/, migrations/, tests/.Version control: Sử dụng GitHub ngay từ đầu. Commit hàng ngày với message rõ ràng (e.g., "Add user registration endpoint").Database: Dùng GORM cho nhanh, hoặc sqlx nếu muốn kiểm soát SQL. Viết migration bằng golang-migrate hoặc goose.Testing: Viết unit test cho service layer, dùng testify để assert. Mock database bằng sqlmock hoặc testcontainers.Tài liệu tham khảo:
Sách: "The Go Programming Language" (Donovan & Kernighan), "Go in Action".
Trang web: Go by Example, Effective Go, Gin Docs.
YouTube: "Go REST API Tutorial" của Traversy Media hoặc freeCodeCamp.
Kiểm tra: Chạy go vet, gofmt, golangci-lint để đảm bảo code sạch. Test API bằng Postman hoặc curl.Trình bày: Quay video demo 2-3 phút chạy API, upload lên YouTube, gửi link trong phần trả bài.6. Yêu cầu về báo cáo cá nhân
